# Height-sensitive run bound: slope B ≤ 1 is impossible

**26 November 2026. Status: the uniform bound (H) is not settled. Every candidate with slope B ≤ 1 is refuted. Fixed-length windows obey an explicit geometric bound.**

This note does not prove the Collatz conjecture, does not produce a divergent orbit, and does not improve the conditional complexity slope 1/log₂(3/2).

Parent question, left open by [FIXED_ODD_PART_MULTIRUN_OBSTRUCTION.md](FIXED_ODD_PART_MULTIRUN_OBSTRUCTION.md): for the shortcut map, with run lengths r_j and run-start values M_j,

\[
\sum_{j=0}^{k-1} r_{i+j} \le A k + B \log_2(M_i+1)
\tag{H}
\]

for every positive integer seed, every i ≥ 0 and every k ≥ 1, with universal constants A, B. A proof of (H) would give a uniform positive lower density of even steps on every infinite orbit. No such proof is claimed here.

## Definitions

T(n) = n/2 if n is even and (3n+1)/2 if n is odd. From a positive integer M, the run length r(M) is v₂(M+1). It is an integer ≥ 0, and M+1 = 2^{r(M)} a with a odd. The next run-start is

\[
M' = (3^{r(M)} a - 1)/2.
\]

Write x(M) = log₂(M+1), δ = log₂ 3 and β = log₂(3/2) = δ − 1. Thus r(M) ≤ x(M), with equality exactly when M+1 is a power of 2.

## Theorem 1. Any constants satisfying (H) must have B > 1

Mersenne numbers already force B ≥ 1. For h ≥ 1 and M = 2^h − 1, the first run has length h = x(M). The case k = 1 of (H) says h ≤ A + B h for every h, so B ≥ 1. The constant B = 1 survives this one-run test.

It does not survive two runs.

**Theorem.** Let A be any real number and let B ≤ 1. The pair (A, B) fails (H).

**Proof.** For m ≥ 3 the multiplicative order of 3 modulo 2^m is exactly 2^{m−2}. Indeed v₂(3² − 1) = 3, and for j ≥ 1 one has v₂(3^{2^j} + 1) = 1, so

\[
v_2(3^{2^{j+1}}-1) = v_2(3^{2^j}-1) + 1.
\]

Hence v₂(3^{2^{m−2}} − 1) = m, while v₂(3^{2^{m−3}} − 1) = m − 1. The subgroup generated by 3 therefore has order 2^{m−2}. It sits inside the units congruent to 1 or 3 modulo 8, a subgroup of the same order, so it equals that set of units.

Now 5 ≡ 5 (mod 8) and 5 · 5 ≡ 1 (mod 8), so 5^{−1} ≡ 5 (mod 8) and −5^{−1} ≡ 3 (mod 8). Thus −5^{−1} is a power of 3 modulo 2^m: some integer r with 1 ≤ r < 2^{m−2} satisfies 5 · 3^r ≡ −1 (mod 2^m), that is v₂(5 · 3^r + 1) ≥ m.

Set M = 5 · 2^r − 1. Then x(M) = r + log₂ 5 and the first run has length r₀ = r, with odd part 5. The next run-start satisfies

\[
M_1+1 = (5\cdot 3^r + 1)/2,
\]

so its run length is r₁ = v₂(5 · 3^r + 1) − 1 ≥ m − 1.

For this window of length k = 2,

\[
r_0 + r_1 \ge r + m - 1, \qquad \log_2(M+1) < r + 3,
\]

because 5 < 8. Among slopes B ≤ 1, the right-hand side of (H) is largest at B = 1, and even then

\[
2A + B\log_2(M+1) < 2A + r + 3.
\]

If m > 2A + 4, then r + m − 1 > 2A + r + 3, so the window exceeds every right-hand side with this A and any B ≤ 1. Such an m exists for every finite A. QED.

The same windows show that the defect at slope 1 is unbounded: on the window above,

\[
(r_0+r_1) - \log_2(M+1) > (m-1) - 3,
\]

which tends to infinity with m. No additive constant A · k with k = 2 can absorb it.

**Explicit window.** The least positive r for m = 16 is r = 757, and v₂(5 · 3^{757} + 1) = 16, so r₁ = 15. For M = 5 · 2^{757} − 1 the two-run sum is 772. Since 5³ = 125 < 128 = 2⁷, one has log₂ 5 < 7/3 and

\[
2\cdot 6 + \log_2(M+1) < 772.
\]

Thus already this single window kills every pair with B ≤ 1 and A ≤ 6. Larger m kill every larger A.

## Theorem 2. Fixed window length is elementary

For every positive integer M and every k ≥ 1, if M_j denotes the run-start after j runs and x_j = log₂(M_j+1), then x_{j+1} ≤ δ x_j and r(M_j) ≤ x_j, so

\[
\sum_{j=0}^{k-1} r(M_j) \le x(M) \sum_{j=0}^{k-1} \delta^j = x(M)\,\frac{\delta^k-1}{\beta}.
\]

The inequality x_{j+1} ≤ δ x_j is the estimate log₂(3^r a + 1) − 1 ≤ r log₂ 3 + log₂ a ≤ δ x_j. Consequently every window of length at most K obeys (H) with A = 0 and

\[
B_K = (\delta^K - 1)/\beta.
\]

For K = 1 this is the sharp value B₁ = 1. For K = 2 it gives B₂ = 1 + δ = log₂ 6 ≈ 2.585. The constant is exponential in K, so it does not give one pair (A, B) for every K.

## What was not refuted

The family of Theorem 1 does not rule out any slope B > 1. Every admissible exponent satisfies 5 · 3^r + 1 ≥ 2^m, hence

\[
r \ge \log_3((2^m-1)/5) > (m - \log_2 5 - 1)/\delta
\]

for m ≥ 2. For B > 1 + δ the linear factor (B − 1)r then dominates m, and a large enough A covers the finitely many small m together with the constant terms. Between B = 1 and B = 1 + δ the size lower bound is too weak to decide, but the least r found for each m ≤ 40 is on the order of 2^{m−O(1)}, which is far larger than m/(B−1).

A direct scan of every odd seed below 100000, and every even seed below 50000, found no window from that seed with

\[
\rho = \Bigl(\sum_{j<k} r_j\Bigr) / \bigl(k + \log_2(M+1)\bigr) > 2.
\]

The maximum on odd seeds is ρ = 1.853…, from the first 13 runs of 27, whose lengths are 2,5,1,2,3,4,1,0,3,2,6,0,4 and whose sum is 33. Since 28³ < 2¹⁶, log₂ 28 < 16/3, and (9/5)(13 + 16/3) = 33 exactly, so

\[
(9/5)\bigl(13 + \log_2 28\bigr) < 33.
\]

Thus 27 kills every diagonal pair A = B = 9/5. It does not kill A = B = 2: 2(13 + log₂ 28) > 33. The even-seed maximum below 50000 is about 1.668, at 54. These scans are finite checks, not a proof that A = B = 2 works.

## Consequence and non-consequence

If some finite A, B did satisfy (H), Theorem 1 would force B > 1, and the resulting positive lower density of even steps on each individual infinite orbit would still be short of the Collatz conjecture: it would not identify the cycle, and it would not by itself raise the conditional complexity slope 1/β. No such pair (A, B) is proved here.

The fixed-odd-part surjection of the parent note remains in force. It forbids bounds that forget the starting height. Theorem 1 forbids the next simplest repair, namely slope B ≤ 1 on that height.
